## 1. Classification & Status Taxonomy

To eliminate ambiguity, every entry in this register is classified using one of the following strict, controlled taxonomy values:

- **VERIFIED_FROM_SOURCE_CODE:** Directly confirmed from inspected algorithmic Python, C++, or Arduino/ESP-IDF firmware source files in the local/remote robotics codebase with exact line numbers.
- **VERIFIED_FROM_CONFIGURATION:** Parameterized in audited configuration files (`controllers.yaml`, `mapper_params_online_async.yaml`, Xacro definitions, or PlatformIO/Arduino board configs).
- **DATASHEET_SPECIFICATION:** Derived directly from official manufacturer technical specifications (e.g., Slamtec A1M8 Datasheet v2.4, Espressif ESP32-WROOM-32 Datasheet v3.9).
- **VERIFIED_FROM_PROJECT_DOCUMENT:** Confirmed from verified institutional records, formal project documentation, or engineering bills of materials (BOM).
- **MEASURED_WITH_TEST_EVIDENCE:** Established via recorded, repeatable experimental logs, sensor scans, or benchmark instrumentation.
- **USER_CONFIRMED_NOT_INDEPENDENTLY_VERIFIED:** Directly asserted by the engineer from physical hardware testing but lacking public third-party or lab instrumentation logs.
- **ILLUSTRATIVE:** Conceptual diagram or UI visual representation explicitly marked as non-telemetry / non-as-built.
- **UNVERIFIED:** Claim inspected and determined to lack empirical test logs; strictly designated as unverified or removed from numerical claims.
- **REMOVED:** Historical claim permanently purged from public pages due to absence of rigorous experimental measurement.

## 4. Discrepancy & External Source Reconciliation Register

1. **Battery Classification & Voltage Grounding (V5.3.3):**
   The project README (`README.md:37`) explicitly lists `24V LiFePO4 battery` and `docs/testing.md:12` records `LiFePO4 under load | PASS - stable at 23.8V`. Inferring that this reading proves an "8S configuration" or exact nominal cell stack voltage without cell datasheet evidence is ungrounded. The portfolio now strictly classifies the subsystem as a **24V-class LiFePO4 battery system**, recording that project test documentation notes a 23.8V reading under operational load, without inferring internal cell series topologies.

2. **Drivetrain Motor Count and Transmission (V5.3.3):**
   The project README (`README.md:42-43`) and system architecture (`docs/system_architecture.md:39`) explicitly state `Rear-wheel drive (24V DC motor)` and `Chain transmission` with a single L298N driver and front steering servo. Earlier portfolio copy had retained a BOM quantity of 2 drive motors and differential-drive torque control references. The portfolio now reflects the documented singular propulsion motor (BOM Qty: 1) driving the rear axle via chain transmission with front steering linkage.

3. **Remote Override & 2.4 GHz RF Subsystem (V5.3.3):**
   The project documentation at `docs/throttle_control.md:8` records a `Manual override lever for emergency takeover` on the mechanical throttle mechanism. The repository does not establish an installed 2.4 GHz RF/Bluetooth teleoperation receiver. All claims of 2.4 GHz wireless transceivers and wireless signal-loss failsafes have been purged from BOM tables, schematics, badges, and résumé, accurately retaining the mechanical emergency override lever.

4. **GPS Source File vs. Architecture Document (V5.3.3):**
   The previous report incorrectly cited an executable source path `src/gps/gps_reader.py`. In reality, the repository contains a ROS 2 node code sample and architectural specification inside `docs/gps_localization.md` lines 16-40. The portfolio now accurately classifies this as documented project architecture and NMEA coordinate acquisition rather than an executable source code module. Furthermore, the field test records of forward driving (0.3 m/s on line 20) and GPS logging (~3 m drift on line 22) are maintained as separate recorded test events rather than a combined simultaneous performance metric.

5. **Furrow Depth: Design Target vs. Qualitative Test (V5.3.3):**
   The numerical claim of "15 cm furrow depth" was not documented in repository drawings or dimensioned specifications; `docs/testing.md:24` only records `Tilling blade | Done | Effective on soft soil`. The unevidenced 15 cm numerical claim has been purged from public schematics, badges, and candidate résumé, retaining the verified qualitative soft-soil tilling blade test.

6. **YIP 7.0 Submission Grounding (V5.3.3):**
